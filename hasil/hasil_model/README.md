# Hasil pemodelan dan evaluasi

Dihasilkan oleh `src/modeling_laundry.py` dari `data_laundry_bersih.xlsx`.

## Isi

- `hasil_model.xlsx`: metrik MAE, RMSE, MAPE, sMAPE, dan bias untuk tujuh model (transaksi dan kilogram), galat per hari, prediksi data uji, parameter Holt-Winters, koefisien regresi, dan contoh perhitungan.
- `10_prediksi_vs_aktual.png`: prediksi dan nilai aktual pada 12 minggu uji.
- `11_perbandingan_metrik.png`: perbandingan MAE dan RMSE antar model.
- `12_galat_per_hari.png`: galat rata-rata per hari dalam seminggu.
- `13_scatter_aktual_prediksi.png`: sebaran nilai aktual terhadap prediksi.
